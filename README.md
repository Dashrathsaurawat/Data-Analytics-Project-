# 📦 BigMart Customer Behavior Analysis (SPSS Project)

## 📑 Project Overview
This project analyzes customer data for BigMart using SPSS.
It focuses on understanding customer demographics, spending behavior, and purchasing patterns to generate actionable business insights.

## 🛠️ Tools Used
- IBM SPSS Statistics
- Microsoft Excel (for basic data handling)

## 📊 Analyses Performed

| Analysis Type                    | Purpose | Outcome |
|:----------------------------------|:--------|:--------|
| **Descriptive Statistics**        | Summarize Age, Income, and Spending Score | Found mean Age = 36 yrs, mean Income = $61k, mean Spending Score = 50 |
| **Frequency Distribution**        | Count occurrences of categories (Gender, Product Category) | Found majority are females; Groceries are most popular |
| **Cross-tabulation**              | Compare Gender and Product Category | Females prefer Groceries & Clothing; Males prefer Electronics |
| **Correlation Analysis**          | Check relationship between Income and Spending Score | No significant relationship found |
| **Independent Samples T-Test**    | Check spending differences between Males and Females | Females spend significantly more |
| **ANOVA**                         | Compare Spending Score across Product Categories | Spending significantly varies by category |
| **K-Means Clustering**             | Segment customers into behavioral groups | 3 customer clusters discovered |
| **Data Visualization**            | Visualize key patterns | Charts and plots created for better interpretation |

## 📚 Key Insights
- Female customers have higher spending scores than males.
- Young low-income customers are surprisingly high spenders.
- Groceries and Clothing are the top-selling categories.
- High income ≠ High spending — marketing should focus on behavior, not income.
- Clear customer segmentation was achieved through clustering.
